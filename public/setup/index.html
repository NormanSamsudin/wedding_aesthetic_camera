Tablet setup

Do this once on the booth tablet. It lets the tablet trust your laptop so the camera can be used.

1. Download the certificate

Download certificate

2. Install it

  1. Open this page in Safari and tap Download certificate, then Allow.
  2. Open Settings and tap Profile Downloaded near the top, then Install.
  3. Go to Settings › General › About › Certificate Trust Settings and turn on Wedding Wish Booth Local CA.
  1. Open this page in Chrome and tap Download certificate.
  2. Open Settings › Security › More security settings › Encryption & credentials › Install a certificate › CA certificate. On some tablets, search Settings for CA certificate.
  3. Tap Install anyway and pick wish-booth-ca.crt from Downloads.

3. Open the booth

It should open without any warning. Allow the camera and microphone when asked.

Open the booth

4. Make it a booth

  1. In Safari tap Share › Add to Home Screen, then open the booth from the new icon so it runs full screen.
  2. Turn on Settings › Accessibility › Guided Access, open the booth, and triple-click the top button to lock the tablet to it.
  3. Set Settings › Display & Brightness › Auto-Lock to Never.
  1. In Chrome tap ⋮ › Add to Home screen, then open the booth from the new icon so it runs full screen.
  2. Turn on Settings › Security › App pinning and pin the booth so guests can't leave it.
  3. Set the screen timeout to the longest option and keep the tablet charging.
